# Part B: AI Video and Prompt Log

**Topic:** Basic Concepts of Agentic AI
**Format:** 6 clips x 10 seconds = 60 seconds, made in Google Flow with a custom AI-generated presenter named Aarav.
**Story:** Each clip teaches one idea, and each idea builds on the previous one.

| Clip | Topic | Key idea |
|---|---|---|
| 1 | What is Agentic AI? | Goal -> Plan -> Act |
| 2 | Traditional AI vs Agentic AI | One answer vs. working until the goal is done |
| 3 | The agent loop | Plan, Act, Observe, Adjust |
| 4 | Tools and memory | How an agent acts and remembers |
| 5 | A real example | Planning a trip with an agent |
| 6 | Recap | Why Agentic AI matters |

## Generation schedule (50 free credits per day, about 15 per clip)
- Day 1: Clips 1, 2, 3
- Day 2: Clips 4, 5, 6
- Day 2 or 3: join the clips in CapCut or Clipchamp, export, upload to YouTube (unlisted) or Drive, and share the link.

## How to use these prompts
1. First create the presenter image "Aarav" (see the character prompt below) and save it in Flow as a character/ingredient named **Aarav**. Every prompt starts with **@Aarav**, which keeps the same presenter in all six clips.
2. Paste one prompt at a time exactly as written. The style block is repeated inside each prompt on purpose, so all six clips look the same.
3. If the on-screen text comes out garbled, regenerate once. If it is still wrong, add the text afterwards in the editor.
4. After generating, write what happened in the "Result and changes" line under each prompt.

## Prompt log: why I chose these prompts and how I improved them

**My first draft (Clip 1)** described a rich story: a normal AI answering, a transformation into an agent, a five-step loop, a moving camera and on-screen text. It was cinematic but too big for 10 seconds.

**What I improved, and why:**
1. **One idea per clip.** A 10-second clip can hold two or three actions. I split the story across six clips so each clip teaches one idea clearly and the video flows as a lesson.
2. **Timed beats.** I added second-by-second actions (0-2s, 2-8s, 8-10s). This gives the model a clear structure and gives the dialogue time to finish.
3. **Matching words.** In the first draft the diagram said THINK but the text said PLAN. I made every label and every spoken word match.
4. **One visual style.** "Realistic presenter" and "clean 3D animation" contradicted each other. I chose a stylized 3D educator and pasted the same style block into every clip, so the six clips look consistent.
5. **Minimal text.** AI video models often garble text, so each clip uses only a few large words.
6. **Shorter dialogue.** I cut each line to about 15 to 20 words so the speech fits naturally into 10 seconds.
7. **Clear rules.** Every prompt ends with the same rules (no extra characters or text, keep the same presenter), which keeps my avatar consistent.

**Prompting method:** I wrote a prompt, generated the clip, checked the result against the rules, and fixed the prompt where it failed. Notes on each clip are in the "Result and changes" lines above.
